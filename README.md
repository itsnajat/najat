PROJECT DESCRIPTION

The student Result Management System is a python-based application developed to
help schools manage student information, record subject-scores, calculate academic results and generate student reports.

The system reduces manual record keeping and makes student result management easier and more organized.

PROJECT OBJECTIVES
. To register and manage student information.
. To record student's subject scores
. To calculate total scores and average scores
. To determine students'grades automatically
. To Search, Update and delete student records.
. To generate individual student result reports.
. To calculate Class Statistics

TECHNOLOGIES USED
. Python
. JSON for data storage
. Object-oriented Programming (OOP)
. Visual Studio Code

SYSTEM FEATURES
. Student Registration
. View All Students
. Search Students
. Update Student Information
. Delete Student
. Enter student Scores
. View Student Results
. Generate Student Reports
. Calculate Class Statistics

HOW TO RUN THE PROJECT

. Download or clone the project respository from GitHub.
. Open the project folder in visual studio code
. Open the terminal
. Run the commmand "python main.py"
. The system menu will appear in the terminal
. Enter the number corresponding to the operation you want to perform

DATA STORAGE

The system uses JSON to store student information and acdemic performance
Student records are saved in the data/students.json file so that information can be retrieved when the program is opened again. The .gitignore file excludes local student records from Git uploads to protect personal information


CONCLUSION

The Student Result Management System demonstrates the application of python programming, functions, object oriented programming, file handling, data structures and exception handfling in solving a real-world educational problem.
